## Background: Training Pipeline Fixes Completed

The training pipeline has been updated with the following improvements (per `.continue-here.md`):

### Quality Validation Gates
- Added to `1_extract_reference_features.py` in TuroArnis-ML
- Rejects images with:
  - YOLO stick detection confidence < 0.5
  - MediaPipe critical joint visibility < 0.7 (wrists, elbows)
  - Physically impossible values (stick_length = 0, angles out of valid range)
- **Result:** 87% reduction in template STDs

### Template Regeneration Results
| Feature | Old Std | New Std | Improvement |
|---------|---------|---------|-------------|
| left_elbow_angle | 60.2° | 7.7° | -87% |
| stick_angle | 48.2° | 3.8° | -92% |

39 templates regenerated (13 classes × 3 viewpoints)

### Neutral Class Addition
- 13 total classes: 12 Arnis techniques + 1 neutral buffer
- Neutral class serves as sink for:
  - Incorrect/wrong poses
  - Non-Arnis movements
  - Transition states between techniques
  - Low-confidence predictions
- Prevents false positives by providing a "none of the above" option

### 3D Angle Calculation
- Upgraded from 2D to 3D angle calculation using MediaPipe world landmarks
- Better distinguishes thrusts (forward z-motion) from blocks (sideways)
- Critical for solving thrust vs block classification confusion

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User→Camera | Physical environment, untrusted lighting/angles |
| Camera→ML Pipeline | Frame processing, detection algorithms |
| ML Pipeline→Classification | Feature extraction, template matching |
| Classification→Feedback | Confidence thresholds, neutral class handling |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5.7-01 | Spoofing | Quality gates | mitigate | Validation gates reject impossible features (stick_length=0), preventing synthetic/corrupted data from poisoning templates |
| T-5.7-02 | Tampering | Template JSON | mitigate | Templates loaded read-only; modifications require git commit + code review; version metadata tracks generation provenance |
| T-5.7-03 | Repudiation | Training logs | accept | Training image rejection reasons logged per-image; sufficient for debugging, not for legal non-repudiation (low-risk domain) |
| T-5.7-04 | Information Disclosure | Neutral class behavior | mitigate | Neutral class provides "soft no" instead of incorrect classification; prevents false confidence in wrong poses; logged for analysis |
| T-5.7-05 | Denial of Service | Template validation | mitigate | Validation gates prevent processing overload from corrupted images; NaN handling prevents GCN crashes from invalid inputs |
| T-5.7-06 | Elevation of Privilege | Model deployment | mitigate | Model files (.pth) loaded with torch.load(map_location='cpu', weights_only=True); prevents pickle deserialization attacks |
</threat_model>
