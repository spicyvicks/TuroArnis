# Phase 5.6: Lesson Mode Similarity Feedback

## Goal
Replace binary correct/incorrect feedback in lesson mode with continuous similarity scoring, showing users how close their pose is to the target technique with actionable percentage-based feedback and textual tips.

## Success Criteria
- [ ] All 3 similarity approaches implemented (simple, variance-weighted, multi-factor)
- [ ] Psychological scoring buffer applied (+5% display adjustment)
- [ ] Snapshot-based capture at peak pose
- [ ] 2-3 contextual tips shown for features below 70% similarity
- [ ] A/B test rotation system collecting comparison data
- [ ] Overlay UI matching existing feedback style

## Decisions

### D-01: Scoring Psychology
**Decision:** Add +5% buffer to all displayed scores (65% actual → 70% display)
**Rationale:** Encourages users while maintaining 65% actual pass threshold

### D-02: Feedback Tip Count
**Decision:** Show 2-3 tips maximum, filtered to features with < 70% similarity
**Rationale:** Prevents overwhelming users while providing actionable guidance

### D-03: Snapshot vs Real-time
**Decision:** Use snapshot capture at peak pose moment
**Rationale:** More stable scores, clearer "hold it" instruction moment

### D-04: A/B Test Approach
**Decision:** Implement all 3 approaches with session-based rotation
**Rationale:** Data-driven selection of best feedback method after ~50 sessions each

```python
class SimilarityCalculator:
    def __init__(self, templates):
        self.templates = templates
    
    def approach1_simple_average(self, hybrid_scores):
        """Simple mean of all hybrid similarity scores"""
        return np.mean(hybrid_scores) * 100
    
    def approach2_variance_weighted(self, hybrid_scores, feature_names, template):
        """Weight by 1/variance (reliable templates count more)"""
        weights = [1.0 / max(template[f]['std'], 0.01) for f in feature_names]
        weighted_scores = [s * w for s, w in zip(hybrid_scores, weights)]
        return sum(weighted_scores) / sum(weights) * 100
```

```python
def generate_lesson_tips(low_features, max_tips=3):
    """Generate 2-3 tips only for features below threshold"""
    tips = []
    
    # Sort by similarity score (lowest first)
    sorted_features = sorted(low_features, key=lambda x: x['score'])
    
    # Take top 2-3
    for feature in sorted_features[:max_tips]:
        tip = get_tip_for_feature(feature['name'], feature['direction'])
        tips.append(tip)
    
    return tips
```
