## Key Decisions Implemented

### D-01: Scoring Psychology
- **Implemented**: +5% buffer applied to all displayed scores
- **Effect**: 65% actual threshold shows as 70% (encouraging)
- **Cap**: Maximum 100% display

### D-02: Feedback Tip Count
- **Implemented**: Maximum 3 tips, filtered to features < 70% similarity
- **Priority**: Lowest similarity features shown first
- **Source**: FEATURE_MESSAGES dictionary for actionable text

### D-03: Snapshot vs Real-time
- **Implemented**: Real-time overlay during COUNTDOWN (throttled to 5th frame)
- **Rationale**: Provides continuous feedback during positioning phase
- **Performance**: <50ms calculation time

### D-04: A/B Test Approach
- **Implemented**: All 3 approaches with session rotation
- **Rotation**: simple → variance → multifactor (persistent across sessions)
- **Data Collection**: Per-session logging with technique, scores, ratings
- **Winner Selection**: Automatic after 50 sessions per approach
