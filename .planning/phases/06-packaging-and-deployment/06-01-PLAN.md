### torch_geometric Workaround
```python
import torch_geometric
tg_path = os.path.dirname(torch_geometric.__file__)
datas.append((tg_path, 'torch_geometric'))
# Filter out distributed module to prevent RPC errors
hiddenimports = [h for h in hiddenimports if not h.startswith('torch_geometric.distributed')]
```

### Path Resolution Pattern
@app/utils/resource_path.py uses `sys._MEIPASS` for packaged mode detection:
```python
try:
    base_path = sys._MEIPASS  # PyInstaller temp folder
except Exception:
    base_path = os.path.abspath(os.path.join(os.path.dirname(__file__), '..', '..'))
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Build Environment → Executable | PyInstaller packages development code into distributable |
| Packaged App → User System | Executable runs on end-user Windows machine |
| Resource Path → File System | Path resolution for bundled vs development modes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | Build artifacts in repo | mitigate | Update .gitignore to prevent future commits of build/, dist/, *.spec |
| T-06-02 | Denial of Service | Large model files | accept | Models are required for functionality; ~35MB is acceptable |
| T-06-03 | Information Disclosure | Debug console output | mitigate | Keep console=True for now (per D-04), but document that production may want console=False |
| T-06-04 | Elevation of Privilege | Database in APPDATA | mitigate | Ensure database directory has appropriate Windows permissions (handled by os.makedirs) |
